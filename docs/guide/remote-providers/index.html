Configure a remote model provider

Lazarus can connect to providers you select, including OpenAI, Anthropic, OpenRouter and compatible API endpoints. Lazarus does not include a first-party hosted model catalog or inference account.

Set up a provider

  1. Open Settings → AI Backends.
  2. Choose a provider or compatible endpoint, then enter its base URL and API key.
  3. Enable the provider and refresh the model list.
  4. Select one of its models in the chat or coding model picker.

Data destination

When you select a remote model, Lazarus sends that provider the prompts and context needed for the request. This can include selected document excerpts, tool results and attached files. Review the provider, its privacy terms and your connected tools before sending sensitive information. Local models use the configured local backend instead.

API keys

Provider keys are stored locally. Lazarus uses the operating system credential store where supported and keeps keys separate from chat history. You can remove or replace a key in AI Backends settings.
