Lazarus

Your AI workspace, running on your terms.

Lazarus brings local models, document search, coding tools and creative workflows into one open-source desktop app. Local models and files stay on your device unless you choose a remote provider or connected tool.

Install Lazarus Read the guide Explore the blog

Local AI tools in one workspace

  • Chat and coding with models managed through local backends.
  • Search your documents and keep memory on your device.
  • Create images, video and audio with local runtimes and models.
  • Manage LoRAs and check compatibility with installed models.

Choose where requests go

Lazarus has no first-party hosted inference service, account, model catalog or memory sync. If you add an API key or compatible remote endpoint, Lazarus sends requests to the provider you configured.
